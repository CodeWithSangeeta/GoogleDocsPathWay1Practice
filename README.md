📱 Jetpack Compose UI Practice Project

This project is a UI-only practice application built using Jetpack Compose.
The tasks were inspired by Google Docs UI design exercises. The goal of this project is to gain hands-on experience with Row, Column, Modifier, Color, Sizing, and Layout management in Jetpack Compose.

🚀 Features Implemented

✅ Basic UI screens (2–3 tasks) created with Jetpack Compose

✅ Used Row and Column for layout structuring

✅ Applied Modifier for spacing, padding, background, and alignment

✅ Experimented with colors and theming

✅ Practiced sizing, weight, and arrangement in UI

🛠️ Tech Stack

Language: Kotlin

UI Toolkit: Jetpack Compose

IDE: Android Studio
